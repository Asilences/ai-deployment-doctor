## 解释范围

本地模型三次都选择了有效的 `(4, 512)`。随机搜索一次也选中完全相同的配置并通过验收。因此这组小样本显示 Agent 的选择在本机重复性较好，**不能证明它相对随机搜索具有显著优势**。三次 Agent 运行基本是同一确定性提案的重复测量，不是三个独立策略。不同运行的参考吞吐存在漂移；配对交替测量缓解单次运行内漂移，但跨运行比较仍有噪声。模型推理的规划成本未纳入吞吐指标，若比较完整优化成本，应另计提案时间与 token 消耗。下一阶段需要扩大独立随机种子、工作负载、模型和机器数量，并报告接受率及优化成本，而不能只展示最佳一次。
