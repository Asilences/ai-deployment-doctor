## 下一步选择

目前优先处理输出完成问题：下一版独立编号，给解释字段明确长度上限并记录 finish_reason；先以单项开发验证检查输出是否闭合，不能截断或修补无效 JSON 后执行，也不修改 verifier。本轮 v3 的 8 次失败保留，不覆盖为新版本结果。

随后再冻结比较协议：独立控制环境、负载与反馈信息；统一候选 ID 机制、可选列表、固定规划服务及每槽位调用上限；随机搜索无放回并使用多个种子；固定规则停止后的未用预算明确报告；以候选槽位预算比较、另列所有实际成本，不能声称总成本天然相等。完整多任务 runner 和正式消融本轮尚未实现。

无历史消融仍会看到通用的未试候选约束，这个约束间接透露访问过的配置；其比较只能解释为去掉语义反馈，不是抹除一切历史信息。环境 / 负载消融也要排除请求中的派生信息。原 2026-09-24 协议与结果保持不变；当前两个任务继续只作为开发任务，不转作确认性 holdout。
